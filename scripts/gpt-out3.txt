## Вердикт: **CONDITIONAL**

Пластик убран. Но заявленная метафора пока не проходит: на `p=0.15` это в первую очередь **исчезающий контур**, а не «проекция потеряла сведение».

Если критерий — «не выглядит как scanline-клипарт», это заметное улучшение. Если критерий — «зритель считывает несведённые лучи без объяснения», это пока **FAIL**.

## 1. Пластик ушёл?

Да.

Убраны главные причины пластикового ощущения:

- нет равномерной хроматики;
- нет растра внутри букв;
- нет псевдо-глянца;
- заливка стала матовой и плотнее к низу;
- циановый цвет теперь работает как контурный акцент, а не как неоновая подсветка.

Но возникла другая проблема: wordmark местами выглядит не как осознанный watermark, а как **почти случайный бледный outline за роботом**.

### `p=0`

Верхняя альфа заливки `0.06` практически не работает. Основную читаемость сейчас дают тонкие контуры, а не сама «чернильная» форма. Для тихого премиального watermark это допустимо, но ты уже находишься у нижней границы видимости.

Я бы поднял умеренно:

```css
background: linear-gradient(
  180deg,
  rgba(13, 17, 23, 0.08),
  rgba(13, 17, 23, 0.22)
);
```

Не выше `0.25` на нижней точке. Иначе снова появится декоративная вывеска вместо фонового слоя.

### `p=0.15`

Сейчас:

```css
opacity: 1 - (0.15 * 3.5) = 0.475
```

Фактические альфы становятся примерно такими:

- заливка: `0.028–0.10`;
- cyan stroke: `0.55 * 0.475 ≈ 0.26`;
- dark stroke: `0.28 * 0.475 ≈ 0.13`.

Для 1px контура на светлом фоне это уже почти пороговая видимость, особенно с дополнительным `blur(0.45px)`.

Моя рабочая настройка:

```css
/* при p=0.15 opacity будет около 0.60 */
opacity: calc(1 - min(1, var(--hero-p, 0) * 2.7));
```

И значения:

```css
.hero-wordmark span {
  background: linear-gradient(
    180deg,
    rgba(13, 17, 23, 0.08),
    rgba(13, 17, 23, 0.22)
  );
}

.hero-wordmark span::before {
  -webkit-text-stroke: 1px rgba(0, 154, 160, 0.60);
}

.hero-wordmark span::after {
  -webkit-text-stroke: 1px rgba(21, 27, 32, 0.32);
}
```

**Stroke оставил бы 1px.** Делать 2px нельзя — сразу появится плакатность и дешёвая техно-графика.

Размер в целом правильный. На скриншоте около 1440px я бы держал wordmark примерно в этом диапазоне:

```css
font-size: clamp(96px, 9.8vw, 144px);
```

Увеличивать его ради читаемости не надо. Проблема не в размере, а в том, что ты одновременно уменьшаешь альфу и размываешь все слои.

## 2. Читается ли «несведение луча» на `p15`?

**Недостаточно.**

Математически сигнал есть:

- левый слой: примерно `-3.1px` по X;
- правый слой: примерно `+3.1px` по X;
- общая разница между ними: `6.2px`;
- по вертикали разница всего около `1.8px`;
- общий blur: `0.45px`.

Но визуально в скриншоте это считывается скорее как:

> «wordmark начал исчезать и слегка расплылся»

а не как:

> «две цветовые регистрации разошлись относительно исходной формы».

Причины:

1. `opacity` применяется ко всему сразу, включая основу.
2. `blur` применяется ко всему wordmark, а не только к эхо.
3. При исчезновении основы глазу не с чем сравнивать смещение.
4. Два симметричных слоя воспринимаются как расширение контура, а не как ошибка сведения.

На `p15` слово уже нужно рассматривать, чтобы увидеть механизм. Для hero-анимации это слишком объяснительно: эффект должен считываться периферийным зрением.

Отдельно: вертикальные cyan-линии рядом с роботом создают более явный «технический» сигнал, чем сам wordmark. В результате зритель может принять их за источник проекции, а надпись — просто за бледный фон.

## 3. Один ход, который сделал бы это интереснее

**Не размывать несущий слой. Размывать только разошедшиеся эхо.**

Сейчас ты размываешь весь объект. Поэтому он превращается в мыло. Оставь матовую основу достаточно стабильной, а blur отдай псевдослоям.

```css
.hero-wordmark {
  opacity: calc(1 - min(1, var(--hero-p, 0) * 2.7));
  translate: 0 calc(var(--hero-p, 0) * -56px);
  filter: none;
  font-size: clamp(96px, 9.8vw, 144px);
}

.hero-wordmark span {
  color: transparent;
  background: linear-gradient(
    180deg,
    rgba(13, 17, 23, 0.08),
    rgba(13, 17, 23, 0.22)
  );
  -webkit-background-clip: text;
  background-clip: text;
  letter-spacing: calc(
    -0.015em + var(--hero-p, 0) * 0.1em
  );
}

.hero-wordmark span::before {
  content: "WEB-STUDIO";
  position: absolute;
  inset: 0;
  color: transparent;
  -webkit-text-stroke: 1px rgba(0, 154, 160, 0.60);
  translate:
    calc(-1px - var(--hero-p, 0) * 18px)
    calc(var(--hero-p, 0) * -7px);
  filter: blur(calc(var(--hero-p, 0) * 2px));
}

.hero-wordmark span::after {
  content: "WEB-STUDIO";
  position: absolute;
  inset: 0;
  color: transparent;
  -webkit-text-stroke: 1px rgba(21, 27, 32, 0.32);
  translate:
    calc(1px + var(--hero-p, 0) * 18px)
    calc(var(--hero-p, 0) * 7px);
  filter: blur(calc(var(--hero-p, 0) * 2px));
}
```

На `p15` получится:

- основа остаётся различимой;
- два контура реально видны по сторонам;
- эхо слегка теряет резкость;
- не появляется ни глитч, ни glow, ни неоновая эстетика;
- эффект читается как оптическое расхождение относительно стабильного источника.

Итог: **направление правильное, но текущий `p15` переусердствует с исчезновением.** Сначала верни устойчивую основу и видимый контраст эхо. Только после этого можно считать метафору работающей.
