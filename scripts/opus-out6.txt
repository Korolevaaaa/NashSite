# РАУНД 5 — СПЕКА + РЕЗКА

Сначала резка. Что я **не** буду делать и почему, чтобы потом не возвращаться:

| Требование | Решение | Причина |
|---|---|---|
| Постеры 9:16 отдельными плитками в портфолио | **РЕЖУ.** Кроп-правило `object-position: 50% 18%` в слоте 4:5 | Постерные плитки ломают ритм скана сетки и дублируют инфу обложки; 9:16 в колонке 330px = 587px высоты, карточка уходит за второй экран |
| Фасеты/сайдбар/3-й уровень таксономии в витрине | **РЕЖУ.** Chips ≤2 уровней + поиск | Владелец сам поставил UX-ограничение «не заблудиться». Трет уровень = дерево, дерево = потерянный посетитель |
| «Настоящая» админка с авторизацией | **РЕЖУ.** localStorage + export JSON + честный бейдж «черновик» | Статика без бэкенда. Любая «авторизация» на клиенте — театр безопасности, посетитель всё равно не увидит данные владельца |
| Рябь «постоянно» | **РЕЖУ.** Duty cycle ~1.5с из 13с | Иначе рейв, а не голограмма |
| 5-й текстовый блок в hero-copy | **РЕЖУ.** Кикер уходит, приходит статус-строка | Кикер «Веб-студия ZETRONIX» дублирует логотип (repetition ban), слот освобождается бесплатно |
| Дипломы в модалке/карусели | **РЕЖУ.** Inline-disclosure | Модалка съест контекст секции, карусель скроет слоты «под загрузку» |
| Inter + Manrope + Space Grotesk | **РЕЖУ все три.** См. п.9 | Unbounded закрывает и латиницу — четвёртая семья не нужна |

## 1. КОМПЕТЕНЦИИ → КНОПКА «ДИПЛОМЫ» + СЛОТЫ

Механика: `grid-template-rows: 0fr → 1fr` (анимируется без JS-замеров высоты), `aria-expanded`, кнопка-pill 44px. Слоты — неинтерактивные dashed-контейнеры 4:3 (диплом ландшафтный), когда владелец положит файл — `<img>` встаёт в тот же слот без смены разметки.

## 2. HOLONAV: СЕКВЕНЦИЯ BEAM→NAV + ГОЛОГРАММА

### 2b. Секвенция (точное значение порога)

Луч живёт от `beam.intensity` (GLB-канал, старт клипа ≈0.68). Панель сейчас включается на `clipP >= 0.7` — почти одновременно, отсюда «нереалистично». Разносим: луч стартует как есть, панель — на **0.80**, и материализация идёт CSS-анимацией, которая срабатывает один раз в момент добавления класса (никаких JS-рендеров).

```ts
// HeroScene.tsx — заменить константы и toggle-блок
const NAV_ON = 0.8;   // было 0.7: ~0.12 clip-прогресса луч светит в пустоту
const COPY_OUT = 0.14;
// ...в update():
stage.classList.toggle("is-nav", clipP >= NAV_ON);
```

Плюс «lock-кольцо» в точке попадания: луч «пристrelивается», панель материализуется. Кольцо добавляется в ProjectorBeam (см. 2c), анимируется тем же классом.

### 2a. Голограмма: слои и точные keyframes

Набор слоёв (панель = 4 слоя, ничего нового в DOM кроме ring в SVG):

1. **Статичные сканлайны** — переезжают в `background` панели (4px период, alpha .04), освобождают `::before`.
2. **`::before` — corner-тики** (4 уголка градиентами): читаемая «голографическая рамка» без новых DOM-узлов.
3. **`::after` — sweep-полоса**, 7.5s infinite, blend `soft-light`, старт через 1.2s после материализации.
4. **Хроматизм текста** — двойной text-shadow ±0.6px cyan/magenta, alpha ≤.3.
5. **Рябь «иногда»** — вторая animation на панели: 13s цикл, возмущение только в окне 84–90% (~0.8с каждые 13с).
6. **Idle-дыхание** — box-shadow pulse 5.5s alternate, амплитуда .10→.18 alpha.
7. **Blink-точка** в `.holo-tag` — статус-диод 3s steps.
