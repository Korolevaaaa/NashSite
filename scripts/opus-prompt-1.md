## Контекст проекта

Сайт веб-студии ZETRONIX (Россия, B2B). React + TypeScript + Tailwind. Первый экран — светлый hero с 3D-роботом, кинетической сеткой на canvas, неоновыми иглами; второй блок — голографическая навигация с проекторным лучом из груди робота.

**НЕЛЬЗЯ трогать:** робота, кинетическую сетку, неоновые иглы, анимацию скролл-перехода, идею проекторной голографической навигации во втором блоке. В hero можно править только текстовый блок hero-copy (кнопки, их расположение, шрифты, тексты).

**Палитра (фиксированная):** фон #f4f4f4, чернила #0d1117 / #151b20, muted #4e5b60, линии rgba(13,17,23,0.12), акцент бирюзовый — текстовый #006b70, декоративный #00c9d4 (на светлом фоне НЕ проходит контраст для текста).
**Шрифты (фиксированные):** Space Grotesk (display), Inter (body), JetBrains Mono (моно-индексы).
**Фирменная кривая:** cubic-bezier(0.16,1,0.3,1). Есть система reveal-анимаций (opacity+translateY при входе в вьюпорт). Поддержка prefers-reduced-motion обязательна. Desktop hover ≠ mobile (тач без hover).

## Какие скилы я использую (чтобы ты трезво оценивал)

**ui-ux-pro-max** — база правил: контраст 4.5:1 минимум, touch-цели ≥44px, анимации 150–300ms по смыслу, никаких декоративных анимаций ради анимации, mobile-first, без горизонтального скролла, focus-visible обязательно, prefers-reduced-motion.

**taste-skill** — методология «дизайн-ДНК»: каждое решение должно иметь форму «Триггер → Решение → Причина → Доказательство»; запрещены описания вида «clean and modern»; нужен хотя бы один trade-off сдержанности (что сознательно НЕ делаем); принцип «если мог написать это не видя сайт — это слоп».

## Что уже забраковано клиентом

- Тёмная/чёрная заливка карточек при hover («черная слоповая хуйня»)
- Текущее состояние: «вырви глаз, взгляд режет и теряется» — клиенту нужно мягко, гармонично, БЕЗ гигантских блоков, не громоздко
- Блоки должны отличаться друг от друга композиционно, но оставаться единой системой

## Твоя задача

1. Жёсткий аудит каждой секции по скриншотам: что сломано в иерархии, ритме, читаемости, уникальности. Без пощады.
2. Предложи дизайн-систему для нижней части страницы: типографическая шкала (заголовки НЕ 64px гигантами — клиент просил мягче), ритм отступов, иерархия (кикер/заголовок/тело/метаданные).
3. Для каждой секции — своя композиция (не список-реестр подряд). Минимум 5 разных паттернов. Опиши каждую и дай код.
4. Порядок чередования: как секции должны «дышать» друг за другом — где плотность, где воздух.
5. Hero-copy: только кнопки/тексты/типографика — можно ли улучшить не ломая.
6. Формат ответа: сначала вердикт списком проблем, потом система, потом per-section спек с кодом.
